# ויקטוריה גרמן – דיאטנית קלינית · nourishvik.com

אתר תדמית סטטי (HTML / CSS / JS ללא build) בעברית, RTL, נגיש ורספונסיבי.
מתארח ב-GitHub Pages מהענף `main` – **כל push ל-`main` עולה לאתר החי תוך דקות.**

## מבנה

| קובץ | תפקיד |
|---|---|
| `index.html` | דף הבית: hero, היכרות, שירותים, "איך זה עובד", יצירת קשר |
| `recipes.html` | מתכונים + חלון מתכון (הנתונים ב-`script.js` תחת `RECIPES`) |
| `blog.html` | "בלוג נושם" – פוסטים מאינסטגרם (ראו למטה) |
| `accessibility-statement.html` | הצהרת נגישות |
| `styles.css` | כל העיצוב. הטוקנים (צבעים, פונטים, מרווחים) בראש הקובץ תחת `:root` |
| `script.js` | תפריט נגישות, ניווט, סימון סקשן פעיל, חשיפה בגלילה, מודאל מתכונים |
| `instagram-posts.js` | רשימת הפוסטים לעמוד הבלוג |
| `images/` | לוגו (PNG שקוף), תמונת פרופיל בכמה גדלים (WebP + JPG), OG image, אייקונים |
| `favicon.svg` / `favicon.ico` | אייקון האתר (סלק מהלוגו) |
| `CNAME` | הדומיין המותאם – לא למחוק |

## עדכון "בלוג נושם"

אין צורך ב-API או בטוקנים. פותחים את `instagram-posts.js`, ומדביקים קישורי פוסטים
ציבוריים מאינסטגרם לרשימה `INSTAGRAM_POSTS` (החדש ראשון):

```js
const INSTAGRAM_POSTS = [
    'https://www.instagram.com/p/XXXXXXXXXXX/',
    'https://www.instagram.com/reel/YYYYYYYYYYY/',
];
```

הפוסטים מוצגים דרך ה-embed הרשמי של אינסטגרם. כשהרשימה ריקה העמוד מציג
כרטיס "עקבו באינסטגרם" במקום.

## עדכון מתכונים

כרטיס המתכון נמצא ב-`recipes.html`, והתוכן המלא (מצרכים, הכנה, ערכים) ב-`script.js`
תחת `RECIPES`, לפי המספר שב-`data-recipe` של הכרטיס.

## שפה ויזואלית

- **צבעים** (מהלוגו): סלק `#B8446A` / `#9E3658` להדגשה וכפתורים, מרווה `#4F6A5A` / `#EDF1EA` לגוונים משניים, קרם `#FBF7F2` כרקע, טקסט `#2A1F1D`.
  כל צמדי הטקסט/רקע נבדקו ליחס ניגודיות 4.5:1 לפחות (WCAG AA).
- **פונטים**: Frank Ruhl Libre לכותרות, Heebo לגוף (Google Fonts).
- **נגישות**: skip-link, `main` landmark, ARIA תקין, מיקוד נראה, `prefers-reduced-motion`, תפריט נגישות עם שמירת הגדרות.

## פיתוח מקומי

אין תלויות. פותחים את `index.html` בדפדפן, או:

```
python3 -m http.server 8000
```

ונכנסים ל-http://localhost:8000.
