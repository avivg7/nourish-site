האתר בעברית מלאה עם תמיכה מושלמת ב-RTL, נגיש ורספונסיבי.

- עיצוב מינימליסטי עם צבעים עדינים ומרגיעים
- אנימציות חלקות ומעודנות
- גרדיאנטים בגוונים של ירוק, בז׳ וורוד עדינים

### 🌐 תמיכה מלאה בעברית ו-RTL
- כל האתר בעברית תקנית
- תמיכה מלאה בכיווניות מימין לשמאל
- תפריט ניווט בצד ימין
- כל הרכיבים מותאמים ל-RTL

### ♿ נגישות מתקדמת
- תפריט נגישות קבוע עם אפשרויות:
  - הגדלת/הקטנת גופן
  - ניגודיות גבוהה
  - שמירת הגדרות אישיות
- תמיכה בקוראי מסך (NVDA, JAWS, VoiceOver)
- ניווט מלא במקלדת
- תגיות ARIA לנגישות מיטבית

### 💬 אינטגרציה עם וואטסאפ

## 🚀 התקנה והפעלה

### דרישות מקדימות
אין דרישות מיוחדות! האתר בנוי עם HTML, CSS ו-JavaScript טהור.

### שלבי התקנה

1. **פתיחת האתר**
   - פתחו את הקובץ `index.html` בדפדפן האהוב עליכם
   - או השתמשו בשרת מקומי (אופציונלי):

   ```bash
   # עם Python 3
   python -m http.server 8000

   # עם Python 2
   python -m SimpleHTTPServer 8000

   # עם Node.js (npx http-server)
   npx http-server
   ```

2. **צפו באתר**
   - פתחו דפדפן והיכנסו ל-`http://localhost:8000`

## 🔧 פתרון בעיות נפוצות

### התפריט לא נפתח בנייד
וודאו שקובץ `script.js` נטען כראוי (בדקו ב-Console)

### צבעים לא מוצגים נכון
נקו את ה-cache של הדפדפן (Ctrl+Shift+R או Cmd+Shift+R)

בדקו שה-JavaScript לא חסום על ידי Ad Blocker או הגדרות דפדפן

### הפונטים לא נטענים
וודאו שיש חיבור לאינטרנט (הפונטים נטענים מ-Google Fonts)
