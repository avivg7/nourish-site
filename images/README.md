# תיקיית תמונות

## הוראות שימוש

### ⚠️ תמונות נדרשות (חובה!)

#### 1. לוגו האתר - `logo.png`
**סטטוס: נדרש מיד!**
- הלוגו מוצג בראש כל דף באתר
- **מפרט מומלץ:**
  - פורמט: PNG (עם רקע שקוף מומלץ)
  - גודל: עד 300px רוחב × 100px גובה
  - יחס גובה-רוחב: מומלץ אופקי (landscape)
  - גודל קובץ: עד 100KB
  - רזולוציה: @2x לתצוגות רטינה

#### 2. תמונת פרופיל - `profile.jpg`
**סטטוס: נדרש**
הוסיפו כאן תמונת פרופיל של התזונאית עם השם `profile.jpg`

**מפרט מומלץ:**
- גודל: 400x400 פיקסלים (או יחס 1:1)
- פורמט: JPG או PNG
- גודל קובץ: עד 200KB (אחרי דחיסה)
- איכות: גבוהה, תמונה ברורה ומקצועית

**טיפים:**
- השתמשו בתמונה עם רקע נקי או מטושטש
- וודאו שהפנים ברורים ומוארים היטב
- דחסו את התמונה עם כלים כמו TinyPNG לפני העלאה
- השתמשו בפורמט WebP לביצועים מיטביים (עם fallback ל-JPG)

### תמונות נוספות
ניתן להוסיף כאן תמונות נוספות לאתר כגון:
- תמונות לגלריה
- תמונות מאמרים
- לוגו
- אייקונים מותאמים אישית

**שמות קבצים מומלצים:**
- `profile.jpg` - תמונת פרופיל
- `logo.png` - לוגו האתר
- `favicon.png` - אייקון האתר (32x32)
- `og-image.jpg` - תמונה לשיתוף ברשתות חברתיות (1200x630)

---

**הערה:** אם אין לכם תמונת פרופיל כרגע, האתר יציג placeholder עד שתוסיפו אחת.
